# Slot-3 Guardrails - BAS Simulator Build

This file mirrors the consulting guardrail intent from:

```text
GP-CONSULTING/OT-SEC/2-BUILD/guardrails/bas-simulator-build-guardrails.md
```

## Allowed

- Synthetic hospital BAS data.
- Fictional equipment and point names.
- Fictional alarm, trend, event, and audit records.
- Local simulator runs.
- Markdown, JSON, JSONL, and CSV evidence generated by the simulator.

## Prohibited

- Real hospital data.
- Real facility diagrams.
- Real credentials, tokens, passwords, VPN details, or vendor support details.
- Real IP addresses, hostnames, VLANs, usernames, screenshots, logs, or point lists.
- PHI or patient records.
- Live BAS/OT scanning.
- Controller writes, point overrides, setpoint changes, schedule changes, or sequence changes against real systems.
- Production-readiness claims.

## Claims

- BUILD may say an artifact was implemented.
- BREAK decides whether behavior was validated.
- PROVE packages evidence.
- Human reviewers own production, safety, and customer-facing claims.
